# 预期股息率计算方法论

本文档详细说明预期股息率的五步计算法。

## 核心概念区分

- **派息率**：公司每赚100元，分给股东多少元。例如派息率30%表示公司盈利100元，分红30元。
- **股息率**：投资者花100元买股票，每年收到多少元分红。例如股息率5%表示投资100元，每年分红5元。

## 五步计算法

### 第一步：分类讨论

根据**业绩稳定性**和**派息率稳定性**将公司分为四类：

| 类型 | 业绩稳定性 | 派息率稳定性 | 特点 | 代表行业 |
|------|-----------|-------------|------|----------|
| **A类** | 稳定 | 稳定 | 盈利能力强，制度健全，分红惯性强 | 银行、公用事业（水电、气、部分油）、电信、铁路（大秦铁路）、茅台等 |
| **B类** | 不稳定 | 稳定 | 公司治理现代化，现金流充足，但行业周期性强 | 海运、除茅台外白酒消费、煤、有色、化工等 |
| **C类** | 稳定 | 不稳定 | 业绩稳定但有大额资本开支需求 | 火电、部分油、水务、燃气、纺织、家电、高铁等 |
| **D类** | 不稳定 | 不稳定 | **不建议新手投资** | - |

**稳定性判断标准**：
- 派息率稳定性：标准差 < 5%为稳定，5-10%为较稳定，>10%为不稳定
- 业绩稳定性：EPS变化率标准差 < 10%为稳定，10-20%为较稳定，>20%为不稳定

### 第二步：测算基准预期股息率

**A类公司**：
1. 计算最近两年平均派息率
2. 预测下一年EPS（可按前三季度同比或留余量）
3. 预期每股分红 = 预期EPS × 平均派息率
4. 基准股息率 = 预期每股分红 ÷ 当前股价

**示例**（招商银行）：
- 2023年派息率：33.92%，2024年：33.99%，平均33.95%
- 预期EPS：5.6元
- 预期分红：5.6 × 33.95% = 1.9元
- 基准股息率：1.9 ÷ 41.2 = 4.61%

**B类和C类公司**：计算方法相同，取最近两年平均派息率。

### 第三步：行业基准纠正（精髓所在）

**A类企业**：
- 一般不需要纠正（分红是惯性强）
- **除非有外力**：
  - 考核目标变化
  - 管理层公开表态（如"提高分红水平"、"保持连续性和稳定性"）

**判断管理层表态的技巧**：
- 连续几年每股分红递增后，管理层表态"提高分红"，则预期不应低于前一年
- 示例：某行2022年0.383元，2023年0.384元，2024年0.405元，2025年表态"提高"，则预期应≥0.405元

**B类企业**：
- 特点：有**周期焦虑**
- 周期顶部：可能下调派息率屯现金（大周期来了）
- 周期底部：可能上调派息率释放现金（平滑波动）

**C类企业**：
- 特点：派息率不稳定主要因为**资本开支**
- 下调派息率情况：
  - 建设新产能
  - 提前囤积原料
  - 并购
  - 大额投资
- 上调派息率情况：
  - 出售业务获得横财
  - 处理持有的金融资产

### 第四步：大股东需求纠正

大股东诉求重要性更高，用于纠正第三步结果。

**需要加大派息率的情况**：
- 大股东急需用钱但未减持股票
- 重要财务投资者有约定的回报要求

### 第五步：公告纠正（确定性最高）

**公司常见公告类型**：
1. 最低派息率承诺
2. 最低分红金额承诺
3. 两者结合的承诺

**示例**（五粮液）：
> 每年派息率不低于70%且不低于200亿

计算方法：
- 若业绩 < 7.36元/股，则每股派息 ≥ 5.15元
- 若业绩 > 7.36元/股，则每股派息 ≥ 业绩 × 70%
- 最低股息率 = 5.15 ÷ 118 = 4.4%

## 稳定性指标计算方法

### 派息率稳定性

```
标准差 σ = √[Σ(xi - μ)² / n]
```

其中 xi 为各年派息率，μ 为平均派息率，n 为年数

| 标准差范围 | 稳定性等级 |
|-----------|-----------|
| σ < 5% | 稳定 |
| 5% ≤ σ < 10% | 较稳定 |
| σ ≥ 10% | 不稳定 |

### 业绩稳定性

基于每股收益（EPS）年度变化率的标准差：

```
变化率 = (EPS本年 - EPS上年) / EPS上年 × 100%
标准差 σ = √[Σ(变化率i - μ)² / n]
```

| 标准差范围 | 稳定性等级 |
|-----------|-----------|
| σ < 10% | 稳定 |
| 10% ≤ σ < 20% | 较稳定 |
| σ ≥ 20% | 不稳定 |

## 投资建议

1. **优先选择A类企业**：确定性高，股息率可能略低但稳定
2. **便宜时可选B/C类**：需要更高股息率作为补偿
3. **A类+高股息率**：发现就先买，稀有机会
4. **D类企业**：新手不要碰

## 注意事项

1. 分类是动态的，不是永久的
2. 始终计算**预期**股息率，而非历史股息率
3. 管理层表态需要仔细揣摩文字含义
4. 行业周期位置判断需要专业分析
5. 公告纠正的确定性最高，应优先考虑
